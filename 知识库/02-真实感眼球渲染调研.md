# 真实感眼球渲染调研

### 眼球构造

- 结构

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902141437477.png)

| Number | Name | Description |
| --- | --- | --- |
| 1 | Sclera | "巩膜"，俗称“眼白”，这个部分会非常湿润，包含少量的触感纹理。 |
| 2 | Limbus | “角膜缘”，存在于虹膜与巩膜之间的深色环形，从侧面看不明显。 |
| 3 | Iris | “虹膜”，一般眼睛的颜色即指虹膜的主要颜色，拥有扩张和收缩功能，调节进入瞳孔的光线，本身更像是圆盘或锥形。 |
| 4 | Pupil | “瞳孔”，眼睛中心的黑点，光线通过这个孔后才会被视网膜的视杆和视锥捕捉到。 |
| 5 | Cornea | “角膜”，角膜是位于虹膜表面上的一层透明的、充满液体的圆顶结构。 |
