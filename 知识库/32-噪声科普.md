# 噪声入门以及在道具里的应用

## 一维噪声

生成一维随机数：

```c
y = fract(sin(x)*100000.0);
```

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902152903397.png)

我们利用正弦函数乘上一个非常大的数，利用fract取小数，把正弦函数打散成0~1的随机数，这样就能生成比较均匀的随机数，而且相比边缘部分，中间更加集中（上下比较白，中间比较黑）。

自然现象中的山脉的形状都是比较奇形怪状的，而我们生成的随机数分布太均匀。在此基础上，我们将x乘上一个10，然后用取整函数floor，将线段分成十个部分，然后对每一个部分都去使用上面的rand函数，生成了十个随机数，将这十个随机数用平滑函数smoothstep顺滑地连起来，就能够生成类似山脉一样的奇形怪状。

```c
x = x * 10.0;
float i = floor(x);  // 整数（i 代表 integer）
float f = fract(x);  // 小数（f 代表 fraction）
y = rand(i); //rand()就是上面的随机函数
y = mix(rand(i), rand(i + 1.0), f);
y = mix(rand(i), rand(i + 1.0), smoothstep(0.,1.,f));//smoothstep相当于生成平缓曲线
```

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902152903406.png)

这种方法就是拓展到二维就是基于晶格生成的噪声，它的思想是类似的。

## 二维噪声

根据wiki，由程序产生噪声的方法大致可以分为两类：

### 白噪声：

在介绍基于晶格方法的噪声前，我们按照上面的思路先来介绍最均匀分布的白噪声。

可以看到，其实白噪声就是分别生成xy两个随机数，并且给xy乘上的系数各不相同。

```glsl
float random (vec2 st) {
    return fract(sin(dot(st.xy,
                         vec2(12.9898,78.233)))*
        43758.5453123);
}

void main() {
    float rnd = random( uv );
    gl_FragColor = vec4(vec3(rnd),1.0);
}
```

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902152903395.png)

### 值噪声：

值噪声非常简单，还记得我们在一维噪声里面，使用floor取整，将一个线段分成了十个部分，我们可以依样画葫芦，使用floor函数，就可以将一个二维平面分成n*n个小晶格（这就是基于晶格的思想），对于每个晶格，我们对每个晶格上的四个顶点，分别生成一个二维随机数，然后用平滑函数将他们混合起来，就生成了二维值噪声。

可以看一下这个示意图

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902152903393.png)

```c
float hash21(vec2 p)
{
        float h = dot(p,vec2(127.1,311.7));

    return -1.0 + 2.0 * fract(sin(h)*43758.5453123);
}

float value_noise(vec2 p)
{
    vec2 pi = floor(p);
    vec2 pf = p - pi;//相当于fract

    vec2 w = pf * pf * (3.0 - 2.0 * pf);//取代smoothstep手动生成平缓曲线

    return mix(mix(hash21(pi + vec2(0.0, 0.0)), hash21(pi + vec2(1.0, 0.0)), w.x),
               mix(hash21(pi + vec2(0.0, 1.0)), hash21(pi + vec2(1.0, 1.0)), w.x),
               w.y);
}
```

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902152903396.png)

可以看到生成的值噪声中，有很多的大色块，一大片的黑色或白色的小方格，看起来像是很模糊的方格块。将晶格更进一步细分后，发现其实值噪声类似把白噪声放大加模糊。

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902152920857.png)

为了消除这种块状，我们又引入了梯度噪声（Gradient Noise）（梯度的意思就是向量）

### Perlin噪声：

柏林噪声的思想也不难，就是对每一个晶格的四个顶点定义一个梯度（就是随机生成的向量），然后将这些梯度分别与当前点到四个顶点的距离向量进行点乘（核心就是多一步点乘啦）。

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902152903402.png)

这里的实现实际是简化版的，我们在算梯度的时候直接取随机值，而没有归一化到单位圆内。（可以多加一步归一化的操作）

```glsl
vec2 hash22(vec2 p)
{
    p = vec2( dot(p,vec2(127.1,311.7)),
              dot(p,vec2(269.5,183.3)));

    return -1.0 + 2.0 * fract(sin(p)*43758.5453123);
}
float perlin_noise(vec2 p)
{
    vec2 pi = floor(p);
    vec2 pf = p - pi;

    vec2 w = pf * pf * (3.0 - 2.0 * pf);

    return mix(mix(dot(hash22(pi + vec2(0.0, 0.0)), pf - vec2(0.0, 0.0)),
                   dot(hash22(pi + vec2(1.0, 0.0)), pf - vec2(1.0, 0.0)), w.x),
               mix(dot(hash22(pi + vec2(0.0, 1.0)), pf - vec2(0.0, 1.0)),
                   dot(hash22(pi + vec2(1.0, 1.0)), pf - vec2(1.0, 1.0)), w.x),
               w.y);
}
```

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902152903398.png)

可以看到生成的噪声中，已经没有很大的色块了，这就是大名鼎鼎的柏林噪声。

### Simplex噪声

simplex噪声是在柏林噪声基础上的进一步优化，想像一下，二维的柏林噪声我们需要做四次点乘操作，那么三维的柏林噪声我们就需要做八次点乘操作，这是非常耗时的。所以，simplex噪声引入了单形的概念，即所在维度空间中最少顶点数量的图形。一维的话是一条线段，二维的话是一个三角形，三维的话就是一个四面体。顶点数量由之前的2^n变成了n+1。

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902152903411.png)

这个算法比较麻烦，这里稍微提一下，有兴趣的可以去看看原博主的讲解。

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902152903394.png)

当输入一点后，找到该点所在的三角形（图中红色三角形），再找到该三角形三个顶点的梯度向量和每个顶点到输入点的差值向量，把每个顶点的梯度向量和插值向量做点乘，得到三个点乘结果。最后，把它们按权重进行叠加混合，这个权重与输入点到每个顶点的距离有关，即每个顶点的噪声贡献度为：

其中，dist是输入点到该顶点的距离向量，grad是该点存储的伪随机梯度向量， 的取值是0.5。

目前需要解决的是如何找到输入点所在的单形？在计算Perlin噪声时，判断输入点所在的正方形是非常容易的，只需要对输入点下取整即可找到，这里可以把单形进行坐标偏斜（skewing），把平铺空间的单形变成一个新的网格结构，这个网格结构是由超立方体组成的，而每个超立方体又由一定数量的单形构成。对应的图解：

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902152903403.png)

之前讲到的单形网格如上图中的红色网格所示，它们有一些等边三角形组成（注意到这些等边三角形是沿空间对角线排列的）。经过坐标倾斜后，它们变成了后面的黑色网格，这些网格由正方形组成，每个正方形是由之前两个等边三角形变形而来的三角形组成。这个把N维空间下的单形网格变形成新网格的公式如下：

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902152903399.png)

经过坐标倾斜后，又回到了熟悉的操作，用floor向下取整就可以获取到对应的正方形顶点坐标，这里要多一步判断当前点是在哪个单形中（在二维情况下，一个正方形由两个三角形组成）

然后依旧是选取梯度，最后求和，求和前首先需要把单形顶点变回到之前由单形组成的单形网格。这一步需要使用第一步公式的逆函数来求得：

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902152903407.png)

最后将求和得到的结果乘上70（这一步是把结果归一化的[-1,1]，70是经过推导得出的结果）

```c
float simplex_noise(vec2 p)
{
    const float K1 = 0.366025404; // (sqrt(3)-1)/2;
    const float K2 = 0.211324865; // (3-sqrt(3))/6;

    //将输入点进行坐标偏移，向下取整得到原点，转换到超立方体空间
    vec2 i = floor(p + (p.x + p.y) * K1);
    //得到转换前输入点到原点距离向量（单形空间下）
    vec2 a = p - (i - (i.x + i.y) * K2);
    //确定顶点在哪个三角形内
    vec2 o = (a.x < a.y) ? vec2(0.0, 1.0) : vec2(1.0, 0.0);
    //得到转换前输入点到第二个顶点的距离向量
    vec2 b = a - o + K2;
    //得到转换前输入点到第三个顶点的距离向量
    vec2 c = a - 1.0 + 2.0 * K2;
    //根据权重计算每个顶点的贡献度
    vec3 h = max(0.5 - vec3(dot(a, a), dot(b, b), dot(c, c)), 0.0);
    vec3 n = h * h * h * h * vec3(dot(a, hash22(i)), dot(b, hash22(i + o)), dot(c, hash22(i + 1.0)));
    //乘以系数，做归一化处理
    return dot(vec3(70.0, 70.0, 70.0), n);
}
```

### 分形噪声

单独一个Perlin噪声虽然也有一定用处，但是效果往往很无趣。因此，Perlin指出可以使用不同的函数组合来得到更有意思的结果，这些函数组合通常就是指通过分形叠加（fractal sum），也就是fbm。

即每一次噪声的采样频率翻倍，而振幅减少一倍。很多文章错误地把这种计算认为是Perlin噪声，这是不对的。Perlin噪声只是对应了其中每一个octave。代码是：

```nginx
float noise_sum(vec2 p)
{
    float f = 0.0;
    p = p * 4.0;
    f += 1.0000 * noise(p); p = 2.0 * p;
    f += 0.5000 * noise(p); p = 2.0 * p;
    f += 0.2500 * noise(p); p = 2.0 * p;
    f += 0.1250 * noise(p); p = 2.0 * p;
    f += 0.0625 * noise(p); p = 2.0 * p;

   return f;
}
```

上面叠加了5层，并把初始化采样距离设置为4，这都是可以自定义的。这种噪声可以用来模拟石头、山脉这类物体。（左下角）

```nginx
float noise_sum_abs(vec2 p)
{
    float f = 0.0;
    p = p * 7.0;
    f += 1.0000 * abs(noise(p)); p = 2.0 * p;
    f += 0.5000 * abs(noise(p)); p = 2.0 * p;
    f += 0.2500 * abs(noise(p)); p = 2.0 * p;
    f += 0.1250 * abs(noise(p)); p = 2.0 * p;
    f += 0.0625 * abs(noise(p)); p = 2.0 * p;

    return f;
}
```

由于进行了绝对值操作，因此会在0值变化处出现不连续性，形成一些尖锐的效果。通过合适的颜色叠加，我们可以用这种噪声来模拟火焰、云朵这些物体。Perlin把这个公式称为turbulence（湍流？），因为它看起来挺像的。（右下角）

```nginx
float noise_sum_abs_sin(vec2 p)
{
    float f = 0.0;
    p = p * 7.0;
    f += 1.0000 * abs(noise(p)); p = 2.0 * p;
    f += 0.5000 * abs(noise(p)); p = 2.0 * p;
    f += 0.2500 * abs(noise(p)); p = 2.0 * p;
    f += 0.1250 * abs(noise(p)); p = 2.0 * p;
    f += 0.0625 * abs(noise(p)); p = 2.0 * p;
    f = sin(f + p.x/32.0);

    return f;
}
```

这个公式可以让表面沿着x方向形成一个条纹状的结构。Perlin使用这个公式模拟了一些大理石材质。（右上角）

### 可平铺噪声

可平铺的噪声就是指那些可以tiling的、seamless的噪声，因为很多时候我们想要让噪声纹理可以无缝连接，例如在生成地形时。按照我们之前提到的方法直接产生噪声，得到的噪声纹理其实是不可以平铺的，你可以看生成纹理的左右、上下其实是不一样的。那么，怎么生成可平铺的噪声纹理呢？

公认比较好的一种方法，就是在2n维上计算n维可平铺噪声。我们以二维噪声为例，如果我们想要得到二维的无缝Perlin噪声，就需要用四维噪声算法来产生。这种方法是思想是，由于我们想要每个维度都是无缝的，也就是当该维度的值从0变成1的过程中，0和1之间比较是平滑过渡的，这让我们想起了“圆”，绕圆一周就是对该维度的采样过程，这样就可以保证无缝了。因此，对于二维噪声中的x轴，我们会在四维空间下的xz平面上的一个圆上进行采样，而二维噪声的y轴，则会在四维空间下的yw平面上的一个圆上进行采样。这个转化过程很简单，我们只需要使用三角函数sin和cos即可把二维采样坐标转化到单位圆上。同样，三维空间的也是类似的，我们会在六维空间下计算。这种方法不仅适用于Perlin噪声，像Worley噪声这种也同样是适合的。

关健部分代码：

```c
//X, Y is [0..1]
float SeamlessNoise( float x, float y, float dx, float dy, float xyOffset ) {
    float s = x;
    float t = y;
    float nx = xyOffset + cos(s * 2.0 * PI) * dx / (2.0 * PI);
    float ny = xyOffset + cos(t * 2.0 * PI) * dy / (2.0 * PI);
    float nz = xyOffset + sin(s * 2.0 * PI) * dx / (2.0 * PI);
    float nw = xyOffset + sin(t * 2.0 * PI) * dy / (2.0 * PI);
    return Noise(nx, ny, nz, nw);
}
```

然而这样的方式过于耗性能，而且四维噪声也很难实现。最近我发现了一种更简单的方式，回想起一下，我们利用晶格生成的噪声，其实是晶格的四个顶点生成随机值，那么只要把随机值在晶格大小中首尾循环，那么我们的mix函数自然得就帮我们平铺过去了，很神奇对吧？

看一下平铺后的代码，用最简单的值噪声进行的修改：

```glsl
float hash21(vec2 p,float scale)
{
    p = mod(p,scale);
    float h = dot(p,vec2(127.1,311.7));
    return -1.0 + 2.0 * fract(sin(h)*43758.5453123);
}
float value_noise(vec2 p,float scale)
{
    p *= scale;
    vec2 pi = floor(p);
    vec2 pf = p - pi;
    vec2 w = pf * pf * (3.0 - 2.0 * pf);
    return mix(mix(hash21(pi + vec2(0.0, 0.0),scale), hash21(pi + vec2(1.0, 0.0),scale), w.x),
               mix(hash21(pi + vec2(0.0, 1.0),scale), hash21(pi + vec2(1.0, 1.0),scale), w.x),
               w.y);
}
```
