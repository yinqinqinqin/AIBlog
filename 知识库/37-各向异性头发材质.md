### 光照模型

对于比较简单的材质shader，我们一般会使用到的比较基础的高光光照模型是Blinn-Phong模型，原理是使用光线方向和视线方向得到的半角向量和法线方向做点乘，作为判断表面光照强度的标准。公式如下：

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902153003577.png)

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902153003571.png)

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902153003576.png)

其中L为光照方向，V为视线方向，H为半角向量，N为法线方向。

对于更真实的PBR材质，为了满足能量守恒而展现出更具说服力的画面，高光的计算可能会用到更加复杂的公式。

对于头发材质，如果仅仅对于单根头发，那么上面的简单光照模型同样也能产生令人信服的效果。然而在实际应用中，我们如果把每根头发都建模出来，最后结果会有非常高的模型面数，这在实时运行的环境中是不可行的。因此我们会使用到头发材质的的模型一般会是像一个头套一样的整块模型。那么要如何在这样的模型上制作出效果较好的头发材质呢？此时就需要引入各向异性材质的概念。

考虑到单根头发在模型表面上造成的微表面效果，也就是如果我们将头发视为极细的圆柱体时，只要半角向量H接近和头发方向T垂直的平面即会看到高光，这是圆柱体在几何上的一种特性。

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902153003573.png)

因此这里引入了Kajiya-Kay Model，这是一种各向异性材质的光照模型。我们可以直接将N和H的点乘替换为T和H的夹角的sin值，以体现上述只要H接近和头发方向垂直的平面就会产生高光的特性。这里对于模型的要求在后面详细介绍。

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902153003580.png)

上图是应用了这个光照模型的的材质球示例。可以看到我们已经能感受到类似于丝绸表面，或者拉丝金属表面的质感，但是对于表现头发还是有一定的不足。

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902153003581.png)

仔细观察可以发现，因为头发的方向并不是每一根都是严密的和模型表面的切线方向相同。因此高光会在切线方向上有一定的jitter效果。于是我们可以为头发的T向量也提供一个偏移量，为形成的高光斑点造成类似的jitter效果。这里对jitter map纹理的要求在后面详细介绍。

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902153003582.png)

这个时候我们已经能有一个好得多的效果了。同时我们注意到，头发高光有一层纹理比较清晰的高频分量，和一层纹理稍显模糊的低频分量。通过两种分量的叠加，我们便能得到效果更好的高光。

最后，我们知道在背光面头发还是会处于阴影处的，因此这时我们仍然还要采用一个经典的漫反射模型。参考资料中使用了

```makefile
l = saturate(lerp(0.25, 1, dot(N, L)))
```

这样做的目的是使阴影边界向背光面有一定的偏移，从而给出更柔和的漫反射光照。

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902153003570.png)

最后加入一个环境光分量便能得到最终效果。

### 其他工作

前面所介绍的光照模型会使用到头发的方向T，那么我们如何在模型的某一点获得头发的方向呢？

有一点我们需要知道：

模型某一点的切线T方向，是在UV空间中的U方向；副切线B方向是UV空间中的V方向。

因此如果我们能够将UV展开的比较有规律，例如让头发方向在UV空间中全部对准V方向，就能直接把模型的副切线作为头发的方向。

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902153003578.png)

```
o.worldNormal = UnityObjectToWorldNormal(v.normal);
o.worldTangent = UnityObjectToWorldDir(v.tangent);
o.worldBitangent = normalize(cross(o.worldNormal, o.worldTangent)) * v.tangent.w;
```

```nginx
float3 N = i.worldNormal;
float3 L = normalize(UnityWorldSpaceLightDir(i.worldPos));
float3 V = normalize(UnityWorldSpaceViewDir(i.worldPos));
float3 H = normalize(V + L);
float3 T = i.worldBitangent;
```

如果遇到拓扑比较复杂的头发模型无法直接将UV展开成如上图所示的情况，那么我们就需要准备一张flow map，用纹理记录当前点的头发在模型表面上的方向，并用TBN矩阵从切线空间转换到世界空间。

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902153003579.png)

上面还提到了我们需要对头发的高光做一定的jitter，因此我们还需要一张jitter map。

为了模拟头发的微表面，这里可以直接用一张噪点图做一下动感模糊得到需要的纹理。

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902153003574.png)

再结合shader：

```bash
float2 jitteredUV = float2(uv.x * jitterH, uv.y*0.1);
float shift = tex2D(_JitterMap, jitteredUV).r * 2 - 1;
return normalize(T + shift * N * jitterV);
```

最后得到jitter后的头发方向T。
