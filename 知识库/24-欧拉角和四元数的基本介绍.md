# 超详细之——图文结合介绍欧拉角和四元数

### 欧拉角简介

欧拉角是用来描述刚体在三维欧几里得空间的朝向(Orientation)的一种方法。它的基本思想是将方位变换分解为三个两两互相垂直轴的三个旋转组成的序列。更直白的说法是，关于刚体旋转的旋转矩阵可以由三个基本旋转矩阵复合得到。(这三个轴是可以任取的，但通常最有意义的是使用模型坐标的三个基向量。这里需要特别说明的是，欧拉角有两种分类方式。其一是根据旋转轴的顺序。这种分类方法又可细分为两种，即常规的欧拉角(Proper Euler-angles)和泰特布莱恩角(Tail-Bryan-angles)。常规欧拉角的选取顺序有 (x,y,x)、(x,z,x)、(y,x,y)、(y,z,y)、(z,x,z)、(z,y,z)这6种，可见选取顺序是a,b,a这样的类型，也就是绕a轴旋转某角度后，绕新生成的b轴旋转一个角度，最后绕两次子旋转以后的a轴再旋转一个角度，以此表示最终的朝向。泰特布莱恩角的旋转轴选取有 (x,y,z)、(x,z,y)、(y,x,z)、(y,z,x)、(z,x,y)、(z,y,x)这6种，也就是遍历笛卡尔坐标系的三轴，比如我们最常见到的Roll-Pitch-Yaw就是其中的一种情况。

然后是根据是绕运动轴还是绕固定轴进行分类。绕运动轴的称为内旋(Intrinsic rotations),绕固定轴的称为外旋(Extrinsic rotations)。这里要特别注意！！！！网上的学习资料绝大多数都没有说明这个问题。然而这是非常重要的概念，会影响到后续旋转矩阵的推导。

### 欧拉角的优缺点

欧拉角的优点非常明显：

1.非常简单，使用三个数就可以表示一个朝向，同时也对内存最友好。(采用的内旋或者外旋，以及什么顺规方式，通常是在一个场景下是固定不变的，所以不需要额外赘述。)

2.非常好理解。最符合人对方位的思考方式。

3.任意三个数都是合法的。我们任意取三个实数，都可以构成合法的欧拉角，即对一个方位的描述。

同时欧拉角也存在非常巨大的问题：

1.对给定的方位，对应的欧拉角不唯一。

2.欧拉角间的插值非常困难

造成第一个问题的原因有两种。第一种是因为三角函数是周期函数。对某个角度加上360º*n，就会造成别名问题。

第二种是因为欧拉角的三次子旋转互相不独立导致的。

例如在顺规xzy内旋的情况下，pitch(绕x轴)135º会等于pitch45º，然后heading180º(绕y轴)最后bank180º(绕z轴).

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902152630410.png)

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902152647838.png)

这两种问题都可以通过限制角度的范围来解决。一种常用的解决方法是将heading和bank限制在180º 到-180º之间。而pitch限制在90º到-90º之间。(P.S如果将三个角度都限制在180º 到-180º之间是无法满足一对一的关系的)

我们可以很容易地限制heading和bank。但pitch的限制，需要一些技巧。这里用伪代码稍微展开说明一下

```c
float wrapTheta(float theta)
{
 theta += Pi;
 theta -= floor(theta * 1.0 / 2 * Pi) * 2.0 *Pi;
 theta -= Pi;
 return theta;
}//只需要简单的加上2Pi的倍数 就可以将角度限制在180º 到-180º之间

void canonsize()
{
// 首先将pitch 限制在180º 到-180º之间
pitch = wrapTheta(pitch)
//接下来将pitch 限制在 90º 到-90º之间
//由于我们之前提到过对给定的方位，对应的欧拉角不唯一。这里的做法即通过改变 heading和bank的
//值，使得pitch 满足限制条件。但这种做法也为插值留下了问题

if(pitch < -Pi/2.0)
{
    pitch = pitch + Pi;
    heading +=Pi;
    bank += Pi;
}
else if(pitch > Pi/2.0)
{
    pitch = Pi - pitch;
    heading +=Pi;
    bank += Pi;
}
...
}

```

在这种约束条件下，对于任意朝向仅存在一个限制欧拉角与其对应。但由于之后会提到的万向锁的存在，这个问题仍没法完全解决。

### 欧拉角造成的万向锁问题

就像我们刚才介绍的欧拉角将3D 空间中任意一个旋转写成了三个矩阵相乘的形式。大部分情况下，我们都能够对三个不同的轴分别进行旋转。但在某些特殊情况下，它的其中两次子旋转可能变换的是同一个轴。(这里同一个轴，无论内旋或者外旋指的都是世界坐标。)

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902152630399.gif)

大部分的学习资料都会使用如上的万向环辅助说明万向锁现象。但我觉得不是很好的说明方法，多个环节很容易混乱。这里我们还是用简单的三维物体来说明。下面给到了一段gif图。

这里我们使用的是内旋，顺规为xyz。

[附件：万向锁_内旋.mov](https://bytedance.larkoffice.com/file/CbPGbG80Hol9MJxdnjlcnARnnId)（[本地附件](./resources/attachments/万向锁_内旋.mov))

首先我们沿着x轴旋转任意度数，注意变换前x轴与世界坐标的x轴是同一方向。然后沿y轴旋转𝜋/2弧度。这里要特别注意的是经过这次子变换后，变换后的z轴与最初的x轴同时也和世界坐标的x轴同向。最后我们需对z轴进行旋转，但此时z轴和最初的x轴重合。所以最后的子旋转和最初的子旋转操纵的是同一个轴。三次旋转变换仅仅覆盖了两个外部轴的旋转。导致丢失了一个自由度。这就是所谓的万向锁问题。

使用外旋的欧拉角也同样会有这个问题。(P.S 看到很多文章都说 外旋/静态 欧拉角不存在死锁问题，这是我困惑的一个点。以我的理解，无论内旋/外旋，都是存在死锁问题的)

### 轴角的优缺点

优点一：同轴的两次旋转可以直接相加来等效为一次旋转。

优点二：定义简单，相对直观。

缺点一：一个坐标系xyz到另一个坐标系x`y`z`，轴角法表示是唯一的吗（角度规定在0-180）？答案是否定的，因为当旋转角度是0的时候，旋转轴可以是任意的，等效为求解 0×x=0 这个方程；也就是说这时候无解了。但是在应用中，一一对应很重要，这也就暴露出了轴角法表示的最致命的问题。

缺点二：两次连续的旋转怎样合成呢？或者说是两个旋转如何做差呢？答案是没办法，除非借助其他表示方法。

##### 2.V⊥的旋转

接下来看垂直的分量V⊥。因为V⊥和u垂直。所以绕u的旋转可以看作是平面旋转。

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902152700657.png)

而由于在平面上我们只有一个V⊥。所以没办法表述V⊥’。即没办法用一个表达式来表示V⊥’。所以我们构造一个同时正交U和V⊥ 的向量w。w可以通过叉乘获得。即w = u x V⊥。(注意这里使用的是右手坐标系)，且由于u是单位向量。很容易得到w的模长和V⊥一致，所以w也在V⊥的旋转圆上。

除了效率问题之外，我们在实现 Slerp 时要注意，如果单位四元数之间的夹⻆ θ 非常小，那么 sin(θ) 可能会由于浮点数的误差被近似为 0.0，从而导致除以 0 的错误．所以，我们在实施 Slerp 之前，需要检查两个四元数的夹⻆是否过小（或者完全相同)。一旦发现这种问题，我们就必须改用 Nlerp 对两个四元数进行插值，这时候 Nlerp 的误差非常小所以基本不会与真正的 Slerp 有什么区别．
