# 故障艺术后处理特效

### RGB颜色分离故障

将RGB三个通道采用不同的uv偏移值进行分别采样。一般情况下，会在这三个颜色通道中选取一个通道使用原始uv值，另外两个进行uv抖动后再进行采样。

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902173720670.gif)

我们可以先用时间系数配合randomNoise产生的噪声来控制不同通道的uv偏移量

```glsl
    float randomNoise(float x, float y)
    {
        return fract(sin(dot(vec2(x, y), vec2(12.9898, 78.233))) * 43758.5453);
    }

    void main()
    {
        float _Intensity = 0.2;   // 整体抖动程度控制
        float splitAmount = _Intensity * randomNoise(u_Time.x, 2.0);

        float colorR = texture2D(_MainTex, vec2(uv.x + splitAmount, uv.y)).r;
        float colorG = texture2D(_MainTex, uv).g;
        float colorB = texture2D(_MainTex, vec2(uv.x - splitAmount, uv.y)).b;

        gl_FragColor = vec4(colorR, colorG, colorB, 1.0);
    }
```

上述代码渲染效果如下

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902173809791.gif)

此外，我们还可以基于三角函数来控制抖动的间隔、幅度、以及抖动的曲线变化

```glsl
 void main()
    {
        float _Amplitude = 0.5;
        float _Amount = 2.0;
        float splitAmount = (1.0 + sin(u_Time.x * 6.0)) * 0.5;  // 值域从[-1, 1]变换到[0，1]
        splitAmount *= 1.0 + sin(u_Time.x * 16.0) * 0.5;
        splitAmount *= 1.0 + sin(u_Time.x * 19.0) * 0.5;
        splitAmount *= 1.0 + sin(u_Time.x * 27.0) * 0.5;
        splitAmount = pow(splitAmount, _Amplitude);
        splitAmount *= (0.05 * _Amount);

        vec3 finalColor = vec3(0.0);
        finalColor.r = texture2D(_MainTex, vec2(uv.x + splitAmount, uv.y)).r;
        finalColor.g = texture2D(_MainTex, uv).g;
        finalColor.b = texture2D(_MainTex, vec2(uv.x - splitAmount, uv.y)).b;

        gl_FragColor = vec4(finalColor, 1.0);
    }
```

三角函数叠加后再配合pow函数结果曲线如下，其中_Amplitude的值大于1时值越大，曲线波动越小，相反，在该参数小于1时值越小，曲线波动约明显。

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902173720665.png)

_Amplitude = 0.5

得到的渲染效果如下

### 错位图块故障

错位图块故障的核心在于生成随机强度且纵横交错的图块，随后基于图块的强度进行uv的抖动采样。

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902173720674.gif)

#### 2.1 基础版本

首先，基于uv和噪声函数生成方块。这里可以使用floor以及上面的randomNoise来实现

```glsl
 float randomNoise(vec2 seed)
 {
        float _Speed = 2.0;    // 方块强度变换速度
        return fract(sin(dot(seed * floor(u_Time.y * _Speed), vec2(17.13, 3.71))) * 43758.5453123);
  }

float _BlockSize = 8.0;
float block = randomNoise(floor(uv * _BlockSize));
```

可以输出随机梯度的均匀方块尺寸的图块强度

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902173720678.gif)

然后我们基于上面这张图像中的强度值做强度的二次筛选，加强整体的随机性

```glsl
float displaceNoise = pow(block, 8.0) * pow(block, 3.0);
```

得到结果如下

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902173720675.gif)

最后我们将上面经过强度二次筛选的图块强度值作为噪声强度的系数，分别对G和B通道进行采样

```glsl
vec3 finalColor = vec3(0.0);
finalColor.r = texture2D(_MainTex, uv).r;
finalColor.g = texture2D(_MainTex, vec2(uv.x + displaceNoise * 0.05, uv.y)).g;  // finalColor.g = texture2D(_MainTex, vec2(uv.x + displaceNoise * 0.05 * rand(7.0), uv.y)).g;
finalColor.b = texture2D(_MainTex, vec2(uv.x - displaceNoise * 0.05, uv.y)).b;  // finalColor.b = texture2D(_MainTex, vec2(uv.x - displaceNoise * 0.05 * rand(13.0), uv.y)).b;
```

渲染效果如下

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902173720667.gif)

#### 2.2 结合RGB颜色分离

可以加上RGB颜色分离的效果来得到更丰富的渲染表现

```glsl
    float randomNoise_2(vec2 seed)
    {
        float _Speed = 10.0;
        return fract(sin(dot(seed * floor(u_Time.y * _Speed), vec2(17.13, 3.71))) * 43758.5453123);
    }

    float randomNoise_1(float seed)
    {
        return randomNoise_2(vec2(seed, 1.0));
    }

    void main()
    {
        float _BlockSize = 8.0;
        float _MaxRGBSplitX = 5.0;    // 水平方向RGB分离最大值
        float _MaxRGBSplitY = 5.0;    // 垂直方向RGB分离最大值

        float block = randomNoise_2(floor(uv * _BlockSize));
        float displaceNoise = pow(block, 8.0) * pow(block, 3.0);  // block强度
        float splitRGBNoise = pow(randomNoise_1(7.2341), 17.0);   // RGB分离值
        float offsetX = displaceNoise - splitRGBNoise * _MaxRGBSplitX;
        float offsetY = displaceNoise - splitRGBNoise * _MaxRGBSplitY;

        float noiseX = 0.05 * randomNoise_1(13.0);
        float noiseY = 0.05 * randomNoise_1(7.0);
        vec2 offset = vec2(offsetX * noiseX, offsetY * noiseY);  // 加入噪声

        vec3 finalColor = vec3(0.0);
        finalColor.r = texture2D(_MainTex, uv).r;
        finalColor.g = texture2D(_MainTex, uv + offset).g;
        finalColor.b = texture2D(_MainTex, uv - offset).b;

        gl_FragColor = vec4(finalColor, 1.0);
    }
```

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902173720662.gif)

#### 2.3 进阶版本

想要得到更加丰富的图块强度，可以通过使用双层BlockLayer的生成配合噪声生成函数randomNoise来进行双层强度的二次筛选，下列代码中_BlockLayerX_U，_BlockLayerX_V代表第X层blockLayer的图块分块数量，_BlockLayerX_Indensity代表第X层BlockLayer中图块的加强程度，_RGBSplit_Intensity代表RGB分离噪声程度。

```glsl
vec2 blockLayer1 = floor(uv * vec2(_BlockLayer1_U, _BlockLayer1_V));  // 求解第一层blockLayer
vec2 blockLayer2 = floor(uv * vec2(_BlockLayer2_U, _BlockLayer2_V));  // 求解第二层blockLayer

float lineNoise1 = pow(randomNoise_2(blockLayer1), _BlockLayer1_Indensity);  // 第一层blockLayer加强
float lintNoise2 = pow(randomNoise_2(blockLayer2), _BlockLayer2_Indensity);  // 第二层blockLayer加强
float RGBSplitNoise = pow(randomNoise_1(5.1379), 7.1) * _RGBSplit_Intensity;  // RGB分离噪声
float lineNoise = lineNoise1 * lintNoise2 * _Offset - RGBSplitNoise;
```

输出图块强度如下

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902173809796.gif)

最后，与2.2中的步骤类似，我们可以基于图块强度进行RGB通道分别采样

```glsl
vec4 colorR = texture2D(_MainTex, uv);
vec4 colorG = texture2D(_MainTex, uv + vec2(lineNoise * 0.05 * randomNoise_1(7.0), 0.0));
vec4 colorB = texture2D(_MainTex, uv - vec2(lineNoise * 0.05 * randomNoise_1(23.0), 0.0));

vec4 result = vec4(vec3(colorR.r, colorG.g, colorB.b), colorR.a + colorG.a + colorB.a);
gl_FragColor = mix(colorR, result, _Fade);
```

### 错位线条故障

该效果的实现思路在于随机宽度线条的生成

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902173809784.gif)

先生成均匀宽度的线条，可以基于trunc函数以及randomNoise来实现

```glsl
    float randomNoise(vec2 c)
    {
        return fract(sin(dot(c.xy, vec2(12.9898, 78.233))) * 43758.5453);
    }

    float trunc_1(float x, float num_levels)
    {
        return floor(x * num_levels) / num_levels;
    }

    vec2 trunc_2(vec2 x, vec2 num_levels)
    {
        return floor(x * num_levels) / num_levels;
    }

    float truncTime = trunc_1(u_Time.x * 10.0, 4.0);     // speed control
    float uv_trunc = randomNoise(trunc_2(uv.yy, vec2(8.0, 8.0)) + 100.0 * truncTime);
```

可得到如下均匀宽度的线条

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902173720671.gif)

紧接着，使用如下代码将均匀渐变线条变为随机梯度的等宽线条

```glsl
float uv_randomTrunc = 6.0 * trunc_1(u_Time.x, 24.0 * uv_trunc);
```

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902173720664.gif)

然后，将随机梯度的等宽线条，经过多次randomNoise操作转换为随机梯度的非等宽线条，下列代码中_LineWidth为线条宽度，值越大线条宽度越窄；_Offset为线条显示程度，范围0-1；_Amount为线条的数量，同时也会影响到线条的强度值，范围0-1，值越小，线条数量越多，强度越强。

```glsl
float blockLine_random = 0.5 * randomNoise(trunc_2(uv.yy + uv_randomTrunc, vec2(8.0 * _LineWidth, 8.0 * _LineWidth)));
blockLine_random += 0.5 * randomNoise(trunc_2(uv.yy + uv_randomTrunc, vec2(7.0, 7.0)));
blockLine_random = blockLine_random * 2.0 - 1.0;
blockLine_random = sign(blockLine_random) * clamp((abs(blockLine_random) - _Amount) / 0.4, 0.0, 1.0);
blockLine_random = mix(0.0, blockLine_random, _Offset);
```

可以得到如下的渲染表现

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902173809793.gif)

接着，通过随机梯度的非等宽线条去抖动uv采样生成的错位线条glitch

```glsl
vec2 uv_blockLine = uv;
uv_blockLine = clamp(uv_blockLine + vec2(0.1 * blockLine_random, 0.0), 0.0, 1.0);
vec4 blockLineColor = texture2D(_MainTex, abs(uv_blockLine));
```

对应效果为

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902173809802.gif)

为了丰富整体的渲染层次，我们可以尝试在glitch的部分加一些色彩变换。其中一种操作是将颜色从RGB转换到YUV空间，对色度和浓度进行偏移

```glsl
vec3 rgb2yuv(vec3 rgb)
{
        vec3 yuv;
        yuv.x = dot(rgb, vec3(0.299, 0.587, 0.114));
        yuv.y = dot(rgb, vec3(-0.14713, -0.28886, 0.436));
        yuv.z = dot(rgb, vec3(0.615, -0.51499, -0.10001));
        return yuv;
}

vec3 yuv2rgb(vec3 yuv)
{
        vec3 rgb;
        rgb.r = yuv.x + yuv.z * 1.13983;
        rgb.g = yuv.x + dot(vec2(-0.39465, -0.58060), yuv.yz);
        rgb.b = yuv.x + yuv.y * 2.03211;
        return rgb;
}

// 将RGB转到YUV色彩空间，进行偏移
vec3 blockLineColor_yuv = rgb2yuv(blockLineColor.rgb);
blockLineColor_yuv.y /= 1.0 - 3.0 * abs(blockLine_random) * clamp(0.5 - blockLine_random, 0.0, 1.0);  // 色度 chrominance
blockLineColor_yuv.z += 0.125 * blockLine_random * clamp(blockLine_random - 0.5, 0.0, 1.0);  // 浓度 chroma
vec3 blockLineColor_rgb = yuv2rgb(blockLineColor_yuv);

// 与源场景图进行混合
vec4 sceneColor = texture2D(_MainTex, uv);
gl_FragColor = mix(sceneColor, vec4(blockLineColor_rgb, blockLineColor.a), _Alpha);
```

### 图块抖动故障

图块抖动故障核心思路在于基于uv的分层抖动。可以采取余数的形式来对uv进行分层，且对于层内的uv数值进行三角函数形式的抖动。

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902173809797.gif)

先用mod函数将uv分层，并对其中一部分进行抖动

```glsl
    uniform float u_frequency;    // uv强度迭代频率
    uniform float u_jitterSpeed;  // 抖动速度
    uniform float u_jitterAmount; // 抖动强度
    uniform float u_splitNum;     // 分层数

    // horizontal glitch
    float pixelSizeY = 1.0 / u_screenHeight;
    float strength = 0.5 + 0.5 * cos(u_Time.y * u_frequency);   // [-1, 1] -> [0, 1]
    float modFlag = step(1.0, mod(uv0.y * u_splitNum, 2.0));    // Mod结果0-1的部分与1-2的部分拆开处理
    vec2 glitchUv = uv0;
    // 抖动方向为水平方向时针对uv.x修改，数值方向时针对uv.y修改
    glitchUv.x = (1.0 - modFlag) * (uv0.x + pixelSizeY * cos(u_Time.y * u_jitterSpeed) * u_jitterAmount * strength) + modFlag * uv0.x;
```

可以得到下面的uv强度变化

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902173720661.gif)

用上面的抖动uv作为输入对场景进行采样即可

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902173720668.gif)

如果想实现左右分层的效果，把分层部分修改成针对uv.x的处理即可，配合针对glitchUV中uv.x或者uv.y的计算来切换左右和上下抖动的效果。

```glsl
float modFlag = step(1.0, mod(uv0.x * u_splitNum, 2.0));
```

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902173720679.gif)

### 扫描线抖动故障

实现虽然简单，但效果具有较强的冲击力。

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902173809787.gif)

其中一个比较直接的方法是直接对水平方向或者竖直方向进行基于randomNoise的抖动，实现如下

```glsl
uniform float u_frequency;   // 抖动频率
uniform float u_threshold;   // 阈值，范围[-1, 1]，抖动幅度大于该阈值的uv才有效果
uniform float u_amount;      // 抖动幅度

float randomNoise(float x, float y)
{
    return fract(sin(dot(vec2(x, y), vec2(12.9898, 78.233))) * 43758.5453);
}

void main()
{
    // horizontal glitch
    float strength = 0.5 + 0.5 * cos(u_Time.y * u_frequency);   // [-1, 1] -> [0, 1]
    float jitter = randomNoise(uv0.y, u_Time.x) * 2.0 - 1.0;   // [0, 1] -> [-1, 1]
    jitter *= step(u_threshold, abs(jitter)) * u_amount * strength;  // 超过threshold的部分进行uv偏移

    vec4 sceneColor = texture2D(u_albedo, fract(uv0 + vec2(jitter, 0.0)));
    gl_FragColor = sceneColor;
}
```

得到效果如下

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902173809794.gif)

也可以在竖直方向抖动

```glsl
float jitter = randomNoise(uv0.x, u_Time.x) * 2.0 - 1.0;
jitter *= step(u_threshold, abs(jitter)) * u_amount * strength;

vec4 sceneColor = texture2D(u_albedo, fract(uv0 + vec2(0.0, jitter)));
```

### 模拟噪点故障

主要思路在于使用noise去扰动原先场景图的颜色值。

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902173720669.gif)

一种常规的代码实现如下，需要注意的是，0.25 * vec3(noiseX, noiseY, noiseZ) - 0.125中的0.25与-0.125的作用是让noise扰动后的画面平均亮度与原先场景相同，不能省略。但是可以进行合适的等幅度缩放，保持相对比例不变即可。

```glsl
uniform float u_speed;   // glitch的长度
uniform float u_fading;  // glitch的透明度

uniform sampler2D u_albedo;

float randomNoise(vec2 x)
{
    return fract(sin(dot(x, vec2(12.9898, 78.233))) * 43758.5453);
}

void main()
{
    vec4 sceneColor = texture2D(u_albedo, uv0);
    vec4 noiseColor = sceneColor;
    float noiseX = randomNoise(u_Time.x * u_speed + uv0 / vec2(-213, 5.53));
    float noiseY = randomNoise(u_Time.x * u_speed + uv0 / vec2(213, -5.53));
    float noiseZ = randomNoise(u_Time.x * u_speed + uv0 / vec2(213, 5.53));

    noiseColor.rgb += 0.25 * vec3(noiseX, noiseY, noiseZ) - 0.125;
    noiseColor = sceneColor + u_fading * (noiseColor - sceneColor);

    gl_FragColor = noiseColor;
}
```

通过以上diamante，可以得到一下非均匀噪声的效果

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902173720660.gif)

我们还可以增加灰度抖动，示例中给出的case是当某一刻的随机强度大于给定的亮度阈值，我们就将原先的RGB颜色设置为对应的Luminance强度，呈现出灰度的表现。

```glsl
// 使用亮度阈值判定是否切换灰度值
float luminance = dot(noiseColor.rgb, vec3(0.22, 0.707, 0.071));
float luminanceFlag = step(u_luminanceThreshold, randomNoise(vec2(u_Time.x * u_speed, u_Time.x * u_speed)));
noiseColor = (1.0 - luminanceFlag) * noiseColor + luminanceFlag * vec4(luminance);
```

### 屏幕跳跃故障

算法原理在于拿到经过时间校正后的uv数值的小数部分，并与原始uv插值，得到均匀梯度式扰动屏幕空间uv，再用此uv进行采样来得到跳动画面的表现。

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902173809798.gif)

核心代码如下：

```glsl
uniform float u_jumpIntensity;  // jump intensity
uniform float u_jumpTime;       // time param
uniform float u_jumpDirection;  // 0: vertical, 1: horizontal

uniform sampler2D u_albedo;

void main()
{
    float directionFlag = step(0.5, u_jumpDirection);

    float jumpH = mix(uv0.x, fract(uv0.x + u_Time.y * u_jumpTime), u_jumpIntensity);
    float jumpV = mix(uv0.y, fract(uv0.y + u_Time.y * u_jumpTime), u_jumpIntensity);
    vec2 usedUv = (1.0 - directionFlag) * vec2(uv0.x, jumpV) + directionFlag * vec2(jumpH, uv0.y);
    vec4 sceneColor = texture2D(u_albedo, fract(usedUv));
    gl_FragColor = sceneColor;
}
```

### 屏幕抖动故障

不同于上述屏幕跳跃故障，屏幕抖动故障采用noise噪声函数来随机扰动uv

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902173809799.gif)

核心代码如下

```glsl
uniform float u_shakeIntensity;  // shake intensity
uniform float u_shakeDirection;  // 0: vertical, 1: horizontal

uniform sampler2D u_albedo;

float randomNoise(float x, float y) {
    return fract(sin(dot(vec2(x, y), vec2(127.1, 311.7))) * 43758.5453);
}

void main()
{
    float directionFlag = step(0.5, u_shakeDirection);
    float shake = (randomNoise(u_Time.x, 2.0) - 0.5) * u_shakeIntensity;
    vec2 usedUv = (1.0 - directionFlag) * vec2(uv0.x, uv0.y + shake) + directionFlag * vec2(uv0.x + shake, uv0.y);
    vec4 sceneColor = texture2D(u_albedo, fract(usedUv));
    gl_FragColor = vec4(uv0.y + shake);
}
```

### 波动抖动故障

核心思路是用双层的noise实现波浪形扭曲uv

#### 10.1 基础版本

核心代码如下

```glsl
    float uv_y = uv0.y * u_screenHeight;
    float noise_wave1 = snoise(vec2(uv_y * 0.01, u_Time.y * u_speed * 20.0)) * (strength * u_amount * 32.0);
    float noise_wave2 = snoise(vec2(uv_y * 0.02, u_Time.y * u_speed * 10.0)) * (strength * u_amount * 4.0);
```

#### 10.2 结合RGB颜色分离

我们还可以加上RGB分离算法，来进一步提升表现力

```glsl
void main()
{
    float strength = 0.0;
    float strengthFlag = step(0.5, u_intervalType);
    strength = (1.0 - strengthFlag) * 1.0 + strengthFlag * (0.5 + 0.5 * cos(u_Time.y * u_frequency));

    // uv
    float uv_y = uv0.y * u_screenHeight;
    float noise_wave1 = snoise(vec2(uv_y * 0.01, u_Time.y * u_speed * 20.0)) * (strength * u_amount * 32.0);
    float noise_wave2 = snoise(vec2(uv_y * 0.02, u_Time.y * u_speed * 10.0)) * (strength * u_amount * 4.0);
    float noise_waveX = noise_wave1 * noise_wave2 / u_screenWidth;
    float uv_x = uv0.x + noise_waveX;

    // rgb split
    float rgbSplitUv_x = (u_RGBSplit * 50.0 + (20.0 * strength + 1.0)) * noise_waveX / u_screenWidth;

    // sample
    vec4 colorG = texture2D(u_albedo, vec2(uv_x, uv0.y));
    vec4 colorRB = texture2D(u_albedo, vec2(uv_x + rgbSplitUv_x, uv0.y));
    gl_FragColor = vec4(colorRB.r, colorG.g, colorRB.b, colorRB.a + colorG.a);
}
```
