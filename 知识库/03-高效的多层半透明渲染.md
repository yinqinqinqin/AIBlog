```

              value: ZERO
            dstColorBlendFactor:
              __class: BlendFactor
              value: SRC_COLOR
            srcAlphaBlendFactor:
              __class: BlendFactor
              value: ONE
            dstAlphaBlendFactor:
              __class: BlendFactor
              value: ONE
            colorWriteMask: 15
            ColorBlendOp:
              __class: BlendOp
              value: ADD
            AlphaBlendOp:
              __class: BlendOp
```

### 发丝中的半透明渲染

#### 遇到的困难

直接应用ShortCut遇到的困难：

1. 发丝仿真需要用Compute Shader，在ios上必现使用metal，而不是OpenGL es，而metal上不支持开fbofetch（在shader中同时读写同一个frame buffer的color texture）。无法实现Pass1.具体看 [移动端的高效渲染 - SubPass.pptx](https://bytedance.feishu.cn/file/boxcnuTQjk37lcydMmGYeAuJn4x)

1. 在安卓上，要实现Pass1，要同时读写3个color texture，性能开销太大。

因而需要对ShortCut方案进行改进，主要针对Pass1.

#### 实现方案

##### >> Pass1 - Accum InvAlpha

所有层的(1-Alpha)累乘存入R16_FLOAT格式的InvAlpha.rt

关闭DepthBuffer的写入和深度测试，开启blendEnable，并设置BlendState为

```plaintext
      colorBlend:
        __class: ColorBlendState
        attachments:
          - __class: ColorBlendAttachmentState
            name: ""
            blendEnable: true
            srcColorBlendFactor:
              __class: BlendFactor
              value: ZERO
            dstColorBlendFactor:
              __class: BlendFactor
              value: SRC_COLOR
            srcAlphaBlendFactor:
              __class: BlendFactor
              value: ONE
            dstAlphaBlendFactor:
              __class: BlendFactor
              value: ONE
            colorWriteMask: 15
            ColorBlendOp:
              __class: BlendOp
              value: ADD
            AlphaBlendOp:
              __class: BlendOp
              value: ADD
```

##### >> Pass2 - Render Depth

继续使用InvAlpha.rt，但是关闭颜色写入，单纯渲染深度（加了一个小偏移）。以下是metal代码：

```
fragment FragmentOutput fragmentShader(
                                        FragmentInput in [[stage_in]],
                                        constant float& u_TransparentStart [[buffer(0)]]
                                       )
{
    FragmentOutput out;
    out.fragColor = float4(0.0);
    out.depth = (in.g_vary_ProjectionPosition.z + 0.002) / in.g_vary_ProjectionPosition.w;
    return out;
}
```

##### >>Pass3 - Render Hair Color

渲染发丝颜色的hairTex.rt与InvAlpha.rt用同一个深度rt，其余同原ShortCut方案。这样就能自动渲染距离相机最近的一定厚度内的多个半透明层。

![图片](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260902141451872.png)

##### >>Pass4 - Resolve Color

同原ShortCut方案。

#### 性能

因为InvAlpha、Depth、Resolve Color3个pass计算都非常简单，性能开销很小，改进的shortcut性能很不错，跟单pass数据很接近，比2pass性能好很多。
