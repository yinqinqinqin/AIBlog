## 性能统计指标（Statistics）

| 名称                     | 说明                                                         |
| :----------------------- | :----------------------------------------------------------- |
| **Frame（帧）**          | 帧耗时指渲染一帧画面总共花费的时间。游戏线程（Game Thread）与绘制线程（Draw Thread）会在一帧完成前同步，因此帧耗时通常与其中某一条线程耗时接近。 |
| **Game（游戏线程）**     | 若帧耗时与游戏线程耗时数值接近，说明游戏性能瓶颈大概率出在**游戏线程**。 |
| **Draw（绘制线程）**     | 若帧耗时与绘制线程耗时数值接近，说明游戏性能瓶颈大概率出在**渲染线程**。 |
| **GPU（显卡）**          | GPU 耗时统计显卡渲染场景所需时长。由于 GPU 运算和帧同步，该数值通常与帧耗时接近。 |
| **RHIT（RHI 线程）**     | 一般情况下，RHI 线程耗时与帧同步，数值通常和帧耗时相近。     |
| **DynRes（动态分辨率）** | 若平台支持且已开启动态分辨率功能，此项会显示主屏分辨率缩放比例、副屏分辨率缩放比例。 |

**RHI**：Render Hardware Interface，渲染硬件接口，UE 抽象封装显卡底层 API 的线程

**瓶颈 (bottleneck)**：性能短板，整条管线最慢的环节，决定帧率上限

**Dynamic Resolution**：动态分辨率，引擎实时缩放渲染分辨率用以稳定帧率

# 项目优化准备设置

游戏编辑器中没有优化，普遍性能没有发布版本好，存储了大量元数据，需要使用发布版本启动编辑器，尽可能减少干扰

![image-20260728200831653](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260728200838818.png)

使用发布版本启动会没有命令行，需要使用测试版本，需要使用==源码编译版本==，而不是标准安装版本，源码编译版本包含发布版本相同的优化，并且保留控制台命令和分析功能

在引擎设置的常规设置里面

1. 关闭平滑帧率![image-20260728201115804](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260728201115923.png)
2. 关闭垂直同步
3. 关闭最大帧率
