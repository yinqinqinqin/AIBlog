# UE中实现波纹效果

在UE中实现波纹效果

![image-20260825171134704](https://yin-qin.oss-accelerate.aliyuncs.com/img/20260825171135038.png)

- 通过射线检测，判断鼠标命中物体
- 每次命中时，在面板上绘制一个圆，最后的结果是在面板上产生一条线
- 想要实现波动效果，需要将上一帧的RT与当前RT进行交换，每次交换时，RT会根据**波动方程**向四周扩散，每次交换都需要减少白色的量，从而达到波纹消散的效果
- 因为UE的蓝图中无法进行RT交换，需要在蓝图中，创建多个材质写入多个RT中，并在蓝图中处理RT之间的交换

当前效果，还可以使用Niagara粒子系统实现。

# 总结分析

- 这个波纹效果的核心是 Render Target 反馈：当前帧写入扰动，下一帧再读取上一帧结果继续扩散。
- 鼠标射线检测只负责确定输入位置，真正的波纹传播依赖 RT 中保存的历史状态。
- 多个 RT 交换是为了模拟上一帧和当前帧之间的关系，蓝图里不能直接原地交换，所以需要手动管理读写目标。
- 波纹消散可以理解为每次扩散时降低强度，让白色区域逐渐变暗，避免波纹无限保留。
- 如果只需要局部视觉反馈，Niagara 粒子也可以实现类似效果；如果需要可被材质继续采样，RT 方案更适合。
